# Data Science Fundamentals

The slides introduce data science, data types, the data-science life cycle,
career roles, and the student-marks case study. These pages are explanatory
rather than standalone Python programs.

- The student marks table and question are on `Slide-1.pdf`, page 14.
- The runnable list-of-dictionaries analysis is
  `../06_Combined_Examples/student_records_analysis.py` (page 15).
- The NumPy student-marks analysis programs are in
  `../06_Combined_Examples/`.

No separate program is placed in this folder because the source slides do not
provide an additional executable program for this topic.
