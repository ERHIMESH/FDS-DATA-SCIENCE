# Python Environment Tools

The source `slide-4.pdf` introduces Python 3.13/3.14, uv, NumPy 2.x,
JupyterLab 4, marimo, and Ruff. It gives no executable uv, JupyterLab, or
marimo examples, so this project does not invent any.

The slide's runnable Ruff commands are recorded in [tool_commands.md](tool_commands.md).
The NumPy installation command is in the root [README.md](../README.md), and
the project dependency is pinned by range in `../requirements.txt`.
